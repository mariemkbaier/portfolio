Applied · EagleProjects Tunisia

Automated annotation, audited before it ships

Hand-labeling a detection dataset is the slowest part of most vision work. This pipeline prompts a zero-shot detector with a class name, slices frames so distant objects stay big enough to see, and turns every surviving box into a SAM 2 instance mask.

The automation is the easy half. What decided whether it was usable was auditing the pseudo-labels for what this architecture actually gets wrong — duplicate merges, slice-edge artifacts, masks on the wrong extent — and spending manual correction only where the audit pointed.

  • Roughly 70% less manual labeling on a thermal dataset
  • Downstream detector at mAP 0.94 on the corrected labels
  • Training-ready exports: YOLO, COCO, Pascal VOC

Research · Concordia University

Test-Time Adaptation under distribution shift

A model trained in one building doesn't stay accurate in the next one — sensors drift, occupancy patterns differ, seasons change. This work adapts the model at inference time, using only the incoming unlabeled stream, and measures how far that gets you.

I benchmark DIGA, PETAL, and PeTTA on tabular sensor data from smart buildings, with ablations isolating what each method actually contributes and where each one collapses under continual shift.

  • Adaptation with no target labels and no retraining
  • Controlled ablations across three adaptation strategies
  • Manuscript in preparation for peer review

Systems · Simulation

Vision-guided pick-and-place, end to end

A camera looks at a table and a 6-DoF arm picks a named object and drops it in a bin. Nothing in the loop is privileged: the robot finds the camera by calibrating, finds the object by looking, and has to know when not to trust what it sees.

The hard part is not any single stage. An error in hand-eye calibration, in 6D pose, or in the solver is indistinguishable from the others by the time it reaches the gripper — so the eval harness exists to attribute error back to the stage that caused it.

  • Hand-eye calibration solving AX = XB, pose from PnP with ambiguity handling
  • Inverse kinematics via damped least squares
  • Twelve bugs found in development, each now a regression test

Prototype · On-device

A meeting assistant that never phones home

Streaming speech recognition, retrieval across company documents and past transcripts, and spoken Q&A answered by a locally hosted model. No external API calls, no per-token cost, and no audio leaving the machine.

Two changes decided whether it was usable. Replacing fixed-interval audio chunking with voice-activity segmentation lifted mean transcription confidence from −0.61 to −0.43 on identical audio. And requiring every extracted action item to quote the transcript verbatim — verified programmatically before it is stored — took fabricated items from 33 to zero on a control meeting.

  • Answers grounded in retrieved passages, with the sources shown
  • Retrieval relevance floor: the model is never called without context
  • Runs entirely on-device — faster-whisper, FAISS, Ollama
