Applied · Annotation tooling

Labeling a detection dataset without labeling it by hand.

A text-prompted annotation pipeline: zero-shot detection over sliced imagery, instance masks from SAM 2, and exports in the formats a training run actually expects. It cut manual labeling by roughly 70% — but the part that decided whether it was usable was auditing what the pipeline got wrong.

How it works

Four stages, one prompt.

The only task-specific input is a text prompt. Nothing in the chain is trained on this dataset.

01

Slice

SAHI cuts each frame into overlapping tiles before inference, so small and distant objects still occupy enough pixels for the detector to see them.

02

Detect

MM-Grounding-DINO runs zero-shot on every tile, prompted with the class name as free text rather than a fixed label set.

03

Merge

Tile predictions are stitched back to full-frame coordinates, with non-maximum merging resolving the duplicates that overlap creates.

04

Segment

SAM 2 turns each surviving box into an instance mask, then everything is written out as detection boxes, instance masks, and semantic PNGs.

The part that matters

Pseudo-labels are a claim, not a result.

A zero-shot pipeline will label every image you give it. It will do that whether or not the labels are any good, and it never tells you which ones it got wrong. Accepting that output as ground truth means training on errors you can't see and evaluating against them too — the failure hides in both halves at once.

So the output was treated as a first pass, not a finished dataset. I audited the pseudo-labels for the failure modes this architecture actually produces — duplicate instances surviving the tile merge, boundary artifacts where an object straddles a slice edge, low-confidence detections on ambiguous thermal signatures, and masks that latch onto the wrong extent of a partially occluded person. Manual correction went where the audit pointed, instead of being spread evenly across the set.

That is where the 70% comes from. Not from trusting the automation, but from knowing precisely which fraction of it needed a human — and the downstream detector reaching mAP 0.94 is the evidence that the remaining labels held up.

The interesting engineering question in auto-labeling isn't "can a foundation model label this?" — it can. It's "how do you find the labels it got wrong, before they become the thing your model learns?"

  • Zero-shot, no fine-tuning — the class is a text prompt, so a new object category needs no retraining
  • Small-object recall via sliced inference rather than a higher-resolution backbone
  • Targeted correction driven by an explicit noise audit, not uniform review
  • Training-ready exports in YOLO, COCO, and Pascal VOC, plus semantic masks
